# Project 01: CMOS Inverter

## Objective

Design and simulate a CMOS inverter using Qucs-S and Ngspice.

## Tools Used

* Qucs-S
* Ngspice

## Project Files

* `cmos inverter.sch` — Circuit schematic
* `export.png` — Exported circuit or simulation image
* `netlist` — Generated simulation netlist

## Working Principle

A CMOS inverter uses a PMOS transistor as the pull-up network and an NMOS transistor as the pull-down network.

* When the input is LOW, the output should be HIGH.
* When the input is HIGH, the output should be LOW.

## Simulation

The DC sweep examines the relationship between input voltage and output voltage.

## Learning Outcome

Learned the basic CMOS inverter structure and how to simulate its voltage transfer characteristic.

## Future Improvements
